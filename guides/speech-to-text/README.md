# Распознавание речи по API

Копия страницы [kosareva.cloud/docs/raspoznavanie-rechi/](https://kosareva.cloud/docs/raspoznavanie-rechi/) от 04.11.2026. Свежие цены: [каталог](https://kosareva.cloud/prices/).

Аудиофайл на вход — текст или субтитры на выход. Протокол тот же, что у Whisper в OpenAI: адрес `/v1/audio/transcriptions`, файл в `multipart/form-data`, ответ в привычных форматах. Ключ и базовый адрес — те же, что у текстовых моделей.

Модель — [Gemini 3.5 Transcribe](https://kosareva.cloud/prices/gemini-3-5-transcribe/) от Google: больше 85 языков, язык определяется сам, есть таймкоды по словам. Минута записи в среднем обходится в 0,55 ₽.

- **Адрес:** `POST /v1/audio/transcriptions` на `https://api.kosareva.cloud`
- **Модель:** `gemini-3-5-transcribe`
- **Файл:** mp3, mp4, m4a, wav, ogg и opus, webm, flac, aac, aiff — до 25 МБ и до часа записи
- **Ответ:** `json`, `text`, `srt`, `vtt`, `verbose_json`
- **Цена:** в среднем 0,55 ₽ за минуту, ошибки не списываются

## Первый запрос

Отправьте файл и имя модели. Без других параметров придёт JSON с полем `text`.

```sh
curl https://api.kosareva.cloud/v1/audio/transcriptions \
  -H "Authorization: Bearer ВАШ_API_КЛЮЧ" \
  -F model="gemini-3-5-transcribe" \
  -F file="@meeting.mp3" \
  -F language="ru"
```

`language` необязателен: без него модель определит язык сама, в том числе если собеседники переходят с одного языка на другой. Если язык известен заранее, укажите его кодом из двух букв — `ru`, `en`, `kk`.

## Python, OpenAI SDK

Если у вас уже есть код под Whisper, менять нужно три строки: ключ, `base_url` и `model`.

```py
from openai import OpenAI

client = OpenAI(
    api_key="ВАШ_API_КЛЮЧ",
    base_url="https://api.kosareva.cloud/v1",
)

with open("meeting.mp3", "rb") as audio:
    result = client.audio.transcriptions.create(
        model="gemini-3-5-transcribe",
        file=audio,
        language="ru",
        prompt="Kosareva Cloud, Kubernetes, PostgreSQL",  # термины и имена — списком
    )

print(result.text)
print(result.usage)  # сколько токенов звука и текста ушло на запрос
```

Модели `whisper-1` у нас нет — инструменту, который подставляет её по умолчанию, укажите `gemini-3-5-transcribe`.

## Субтитры: srt и vtt

Попросите `response_format` `srt` или `vtt` — придёт готовый файл субтитров, фразы разбиты по паузам и концам предложений.

```py
with open("lecture.mp3", "rb") as audio:
    subtitles = client.audio.transcriptions.create(
        model="gemini-3-5-transcribe",
        file=audio,
        response_format="srt",  # или "vtt"
    )

with open("lecture.srt", "w", encoding="utf-8") as file:
    file.write(subtitles)
```

```sh
curl https://api.kosareva.cloud/v1/audio/transcriptions \
  -H "Authorization: Bearer ВАШ_API_КЛЮЧ" \
  -F model="gemini-3-5-transcribe" \
  -F file="@lecture.mp3" \
  -F response_format="srt" \
  -o lecture.srt
```

## Таймкоды фраз и слов: verbose_json

В `verbose_json` кроме текста есть длительность записи, фразы с началом и концом в секундах и каждое слово отдельно.

```py
with open("call.wav", "rb") as audio:
    result = client.audio.transcriptions.create(
        model="gemini-3-5-transcribe",
        file=audio,
        response_format="verbose_json",
        timestamp_granularities=["word"],
    )

print(result.duration)  # длительность записи, секунды
for segment in result.segments:
    print(f"{segment.start:7.2f}–{segment.end:7.2f}  {segment.text}")
for word in result.words[:5]:
    print(word.word, word.start, word.end)
```

Фразы и слова приходят в `verbose_json` всегда, параметр `timestamp_granularities` можно не передавать.

## Параметры запроса

| Поле | Что задаёт |
|---|---|
| `file` | Запись: mp3, mp4, m4a, wav, ogg и opus, webm, flac, aac, aiff. Весь запрос вместе с файлом — до 25 МБ. Обязательно |
| `model` | `gemini-3-5-transcribe`. Обязательно |
| `language` | Код языка из двух букв, например `ru`. Без него язык определяется сам |
| `prompt` | Термины, имена и названия через запятую — модель возьмёт их как словарь. Связный текст здесь не учитывается, а в форматах с таймкодами словарь не работает |
| `response_format` | `json` (по умолчанию), `text`, `srt`, `vtt`, `verbose_json` |
| `timestamp_granularities` | Принимается для совместимости: в `verbose_json` и так есть фразы и слова |
| `temperature` | Принимается, но на расшифровку не влияет |

## Что работает через kosareva.cloud

Коротко: файл целиком в текст или субтитры — да; живая расшифровка, перевод и разделение говорящих — нет.

### Текст и субтитры работает

Форматы `json`, `text`, `srt` и `vtt` — для протоколов совещаний, заметок и видео.

### Таймкоды фраз и слов работает

В `verbose_json` — начало и конец каждой фразы и каждого слова в секундах.

### Определение языка работает

Больше 85 языков, язык определяется сам — в том числе когда собеседники переходят с одного на другой.

### Словарь терминов с оговорками

Поле `prompt` со списком имён и терминов работает в `json` и `text`, а в форматах с таймкодами — нет.

### Длинные записи с оговорками

До часа и 25 МБ на запрос, с таймкодами (`srt`, `vtt`, `verbose_json`) — до 30 минут. Длинное режьте на части по паузам, большие файлы сжимайте: час речи в mp3 на 48 кбит/с занимает около 21 МБ.

### Живая расшифровка нет

Файл отправляется целиком, ответ приходит, когда распознана вся запись; `stream` не поддерживается.

### Перевод речи нет

Пути `/v1/audio/translations` нет — только распознавание на языке записи.

### Разделение говорящих нет

Модель это умеет, но через наш API пока не отдаёт.

### Распознавание в кабинете без кода нет

Только по API.

## Сколько стоит

Цена считается по токенам, как у самой модели: звук — 216 ₽ за миллион токенов, это 25 токенов на секунду записи, то есть около 0,32 ₽ за минуту; текст расшифровки — 1 296 ₽ за миллион токенов. Минута обычной речи в среднем выходит 0,55 ₽: плотная речь чуть дороже, запись с паузами — дешевле.

| Запись | Примерно |
|---|---|
| Голосовое сообщение на 30 секунд | ≈ 0,28 ₽ |
| Звонок на 5 минут | ≈ 2,75 ₽ |
| Совещание на час | ≈ 33 ₽ |

Сколько ушло на конкретный запрос, видно в расходах кабинета, а в форматах `json` и `verbose_json` — ещё и в поле `usage` ответа. В `text`, `srt` и `vtt` ответ — голый текст, поля `usage` там нет. Запрос, который закончился ошибкой, не списывается.

## Устранение неполадок

Ошибка приходит в формате OpenAI с объяснением по-русски, деньги за неё не списываются. Исключение по форме — 413: слишком большой запрос отклоняется ещё на входе, тело такого ответа не JSON, поэтому смотрите на код ответа.

### 400: файл или параметры не подошли

Нет файла, файл пустой, формат не звуковой, модель не для распознавания (например, `whisper-1`), неизвестный `response_format` или запись длиннее допустимого — час, а с таймкодами 30 минут.

[Ошибка 400 API](https://kosareva.cloud/spravochnik/oshibka-400-api/)

### 413: запрос больше 25 МБ

Сожмите файл — час речи в mp3 на 48 кбит/с занимает около 21 МБ — или разрежьте запись на части по паузам.

### 401: «Ключ не найден» или «Ключ не принят»

Ключ скопирован не целиком или удалён в кабинете. Нужен заголовок `Authorization: Bearer ВАШ_API_КЛЮЧ` с ключом из нашего кабинета — ключ OpenAI не подходит.

[Ошибка 401 API](https://kosareva.cloud/spravochnik/oshibka-401-api/)

### 402: «Закончились средства на балансе»

Пополните баланс в [кабинете](https://kosareva.cloud/panel/) картой или СБП — от 50 ₽. Если деньги есть, проверьте, не стоит ли у ключа свой лимит в рублях.

[Insufficient credits (402)](https://kosareva.cloud/spravochnik/insufficient-credits/)

### 429: модель перегружена

Повторите запрос через минуту, лучше с растущей паузой.

[Rate limit exceeded](https://kosareva.cloud/spravochnik/rate-limit-exceeded/)

### 502 или 504

Сбой или долгий ответ на стороне модели — повторите запрос. Длинную запись надёжнее отправлять частями.

[Ошибка 500 API](https://kosareva.cloud/spravochnik/oshibka-500-api/) · [Таймаут и connection error](https://kosareva.cloud/spravochnik/api-timeout/)

## Частые вопросы

### Подойдёт ли код, написанный под Whisper?

Да. Менять нужно ключ, `base_url` и имя модели — `gemini-3-5-transcribe` вместо `whisper-1`. Формат запроса и ответа тот же.

### Какие языки распознаются?

Больше 85 языков. Язык определяется сам, в том числе когда собеседники переходят с одного на другой; если он известен заранее, передайте `language`.

### Сколько стоит час записи?

В среднем около 33 ₽: минута обычной речи — 0,55 ₽. Точная сумма зависит от плотности речи и видна в расходах кабинета.

### Можно ли расшифровать запись длиннее часа?

Одним запросом — нет: до часа и до 25 МБ, с таймкодами — до 30 минут. Разрежьте запись на части по паузам и отправьте по очереди.

### Разделяет ли модель говорящих?

Через наш API — пока нет: придёт сплошной текст или фразы с таймкодами без подписи, кто говорит.

### Можно ли распознавать речь в реальном времени?

Нет. Файл отправляется целиком, ответ приходит после распознавания всей записи.
