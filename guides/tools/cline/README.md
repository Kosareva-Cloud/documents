# Cline

Отдельного файла конфигурации у Cline нет: настройки хранятся внутри VS Code,
поэтому поля вводятся руками один раз.

1. Установите расширение Cline в VS Code.
2. В настройках Cline в поле **API Provider** выберите **OpenAI Compatible** —
   это режим для любого эндпоинта формата OpenAI.
3. Заполните три поля:

```text
Base URL   https://api.kosareva.cloud/v1
API Key    ваш ключ из https://kosareva.cloud/panel/
Model ID   claude-sonnet-5
```

Имя модели — любое из каталога https://kosareva.cloud/prices/. Для работы с
кодом обычно берут `claude-sonnet-5`, для экономии — `deepseek-v4-flash`.

## Что учесть

- Агент отправляет модели содержимое файлов, которые открывает. Это основной
  расход токенов: чем больше проекта в контексте, тем дороже запрос.
- Автоматическое одобрение команд выполняет их без вопроса. На чужом или
  боевом проекте подтверждения лучше оставить.
- Нулевой баланс блокирует запросы — пополните его в кабинете.

Полная инструкция: https://kosareva.cloud/instrumenty/cline/
