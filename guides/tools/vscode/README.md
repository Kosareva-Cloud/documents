# Расширение Kosareva Cloud для VS Code

Расширение даёт модели каталога родному чату и agent mode редактора. Своего чата, автодополнения по Tab и агента у него нет: всё это остаётся за VS Code.

## Установка

1. Откройте вкладку расширений (`Ctrl+Shift+X`), введите `kosareva` и нажмите **Install**. Идентификатор расширения: `kosareva-cloud.kosareva-cloud`, [страница в Marketplace](https://marketplace.visualstudio.com/items?itemName=kosareva-cloud.kosareva-cloud).
2. Нажмите `Ctrl+Shift+P` и выберите команду **kosareva.cloud: Подключить ключ**. Ключ берётся в [кабинете](https://kosareva.cloud/panel/) и начинается с `sk-`.
3. В списке моделей чата нажмите **Add Models → kosareva.cloud** и отметьте нужные модели. Пока этого не сделано, в чате их не будет.

## Что расширение делает

- Показывает модели каталога в чате VS Code и в agent mode.
- Хранит ключ в SecretStorage VS Code, а не в `settings.json`.
- Показывает баланс в статус-баре.
- Настраивает Continue и Codex CLI, рядом кладёт `.bak`. Для Claude Code и Cline кладёт готовые значения в буфер обмена.

Телеметрии нет. Кроме запросов к модели, которые вы отправляете из чата, наружу уходят три служебных запроса: проверка ключа, баланс и список моделей. Команда «Проверить связь» делает один платный запрос к модели и сначала спрашивает разрешение.

## Чего здесь нет

Своего чата, автодополнения по Tab и своего агента. Исходного кода расширения в открытом доступе пока тоже нет.

Полная инструкция: https://kosareva.cloud/vscode/
