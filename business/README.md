# Kosareva Cloud: AI API для бизнеса

[English version](README.en.md)

Kosareva Cloud даёт компаниям один API к более чем 170 моделям в форматах OpenAI и Anthropic.

**Мы работаем только через настоящий API вендоров и не используем подписки ChatGPT, Claude Code или IDE как канал для API.**

Работаем через российское ИП или через армянское ООО, вы выбираете, что удобнее. Оплата в рублях с расчётного счёта. Перед отправкой в модель данные можно маскировать через API Guard. Если своих рук на интеграцию не хватает, подключим сами или сделаем бота под задачу.

Эта страница для тех, кто отвечает за разработку, закупку или безопасность и сейчас решает, можно ли пустить такой API в компанию. Что у нас есть, написано со ссылками и цифрами. Чего нет, собрано в [отдельный раздел](#чего-у-нас-нет).

## API Guard: маскирование данных

Запрос в зарубежную модель это передача текста за пределы вашего контура. API Guard находит в запросе чувствительные данные, заменяет их заглушками, а в ответе разворачивает обратно, в том числе в потоке. Модель видит `[[EMAIL_1]]`, ваш код получает настоящий адрес.

Подключается заменой одного адреса, ключ и баланс те же:

| SDK | Адрес |
|---|---|
| OpenAI, Chat Completions и Responses | `https://api.kosareva.cloud/guard/v1` |
| Anthropic | `https://api.kosareva.cloud/guard` |

Guard распознаёт 22 типа данных:

- люди: ФИО с отчеством или инициалами, почта, телефон, паспорт РФ, водительское удостоверение, СНИЛС;
- реквизиты: ИНН, ОГРН и ОГРНИП, расчётный счёт, карта, CVV, IBAN, БИК;
- доступы: ключи и токены, приватные ключи, строки подключения, пароли;
- техника и автомобили: IP, MAC, госномер, VIN, ОСАГО.

Ещё три типа включаются заголовком: дата, ссылка и строка с высокой энтропией. Проверяются сообщения всех ролей, аргументы и ответы инструментов, описания инструментов в форматах Chat Completions, Messages и Responses. Соответствие «заглушка и оригинал» живёт только в памяти одного запроса, в журнал идут только счётчики.

Заголовками можно задать типы (`X-Guard-Types`), пропустить запрос без маскирования (`X-Guard-Off`), запретить отправку вместо маскирования (`X-Guard-Deny`) и закрыть вложения (`X-Guard-Files`). `POST /guard/v1/guard/preview` показывает результат, ничего не отправляя в модель.

Guard наша разработка, на проверку данные третьей стороне он не отправляет. Подробнее на [kosareva.cloud/api-guard/](https://kosareva.cloud/api-guard/).

## Где лежат данные

Кабинет, база пользователей, биллинг и журналы расхода лежат в дата-центре в Москве. Тексты запросов и ответов в журналы нашего шлюза не записываются, остаются модель, токены, время и стоимость. Обещание касается только нашего шлюза, журналы дальше по маршруту мы не контролируем. Для картинок, видео, музыки и озвучки есть исключения, они перечислены в [принципах](../principles/README.md#4-данные).

Запрос к зарубежной модели уходит за пределы России, это трансграничная передача с отдельного согласия. Согласие даёт владелец аккаунта отметкой при регистрации. За данные ваших клиентов и сотрудников в запросах отвечаете вы как оператор, эта отметка их не покрывает. Модели с меткой «Модель в РФ» работают в российском ЦОД, запрос не покидает страну.

Как это устроено, написано на странице [kosareva.cloud/legal/152-fz/](https://kosareva.cloud/legal/152-fz/). Она описывает сервис и не заменяет вывод вашего юриста.

## Чем подтверждён наш опыт

Клиентов мы по именам не называем, и громких цифр о внедрениях здесь нет. Зато своё можно посмотреть руками:

- **Шлюз.** Перед моделью стоит наш шлюз: он чинит частые ошибки в запросах, переводит сообщения об ошибках на русский, следит за первым байтом ответа и при сбое уводит запрос на резервный маршрут, если он есть.
- **API Guard.** Маскирование данных, описанное выше.
- **Бот поддержки на базе знаний.** Отвечает в чате на нашем сайте.
- **Расширение для VS Code.** [Опубликовано в Marketplace](https://marketplace.visualstudio.com/items?itemName=kosareva-cloud.kosareva-cloud), даёт модели родному чату редактора.
- **[Скиллы](https://kosareva.cloud/skills/) и [справочник ошибок](https://kosareva.cloud/spravochnik/).** Открыты на сайте, регистрация не нужна.
