# Принципы Kosareva Cloud

Редакция от 04.11.2026. [English version](README.en.md).

Kosareva Cloud даёт компаниям и разработчикам один API к моделям OpenAI, Anthropic, Google, xAI, DeepSeek, Moonshot AI, Qwen, MiniMax, GigaChat, YandexGPT и других вендоров. Мы работаем только через настоящий API вендоров и не используем подписки ChatGPT, Claude Code или IDE как канал для API. Ниже записано, что мы обещаем, как это устроено и как вы проверите это сами. То, чего у нас нет, собрано в отдельный раздел.

## 1. Форматы вендоров

Мы работаем в форматах вендоров: OpenAI Chat Completions и Responses, Anthropic Messages. Поэтому подходят официальные SDK и готовые инструменты, меняются только адрес и ключ.

У моделей с вызовом функций: если есть свой поиск, работает он, если нет, запрос выполняет наш шлюз, и потоковый ответ приходит одним куском, когда готов. GPT 5.4 и новее с `reasoning_effort` в chat поиска не получают, для них есть Responses API. Поиск через шлюз ограничен пятью поисками на запрос, чтение страниц берёт до 20 тысяч символов, без PDF и страниц со входом по паролю.

Если у модели есть резервный маршрут, при сбое запрос уходит на него.

`GET https://api.kosareva.cloud/v1/models` с вашим ключом покажет каталог, а любую возможность вы проверите запросом к своей модели. Наши живые проверки поиска и инструментов прошли 19–22.10.2026.

## 2. Только настоящий API вендоров

**Мы работаем только через настоящий API вендоров и не используем подписки ChatGPT, Claude Code или IDE как канал для API.**

Между вашим кодом и моделью стоит наш шлюз, дальше запрос идёт по нашим каналам. Если у модели есть резервный маршрут, при сбое запрос переходит на него. Выбрать конкретный канал клиент не может. Открытого списка каналов нет, для договора с поручением обработки данных условия обсудим до подписания.

## 3. Цены открыты

Цены указаны в рублях на странице каждой модели. Абонентской платы нет, деньги списываются по факту за токены, картинки, символы, ролики или треки, смотря по модели. Веб-поиск у большинства моделей оплачивается отдельно за каждый вызов. По оферте цена в счёте равна опубликованной.

Расход виден в кабинете по каждому ключу. На ключ можно поставить лимит в рублях.

Проверить можно без ключа и без регистрации:

```sh
curl -s https://kosareva.cloud/panel/api/price-catalog
```

В ответе весь каталог с ценами в рублях.

## 4. Данные

Кабинет, база пользователей, биллинг и журналы расхода лежат на сервере в дата-центре в Москве.

Тексты запросов и ответов в журналы нашего шлюза не записываются, остаются модель, число токенов, время и стоимость. Исключения: картинки встроенного чата кабинета вместе с текстом запроса хранятся до 180 дней или до удаления. Видео и музыка, в том числе созданные через API, и озвучка из кабинета хранятся в базе кабинета вместе с первыми 1000 символами запроса, срока хранения у них нет. Картинки, которые API отдаёт ссылкой, могут лежать на нашем сервере сутки. Резервные копии базы кабинета хранятся 14 дней.

Запрос к зарубежной модели уходит за пределы России, это трансграничная передача с отдельного согласия. Согласие даёт владелец аккаунта отметкой при регистрации. За данные ваших клиентов и сотрудников в запросах отвечаете вы как оператор, эта отметка их не покрывает. Модели с меткой «Модель в РФ» работают в российском ЦОД, запрос не покидает страну. Для них есть ключ «Только модели в РФ», он доступен всем клиентам.

Если данные всё же идут в зарубежную модель, их можно маскировать. API Guard заменяет заглушками 22 типа данных до отправки и разворачивает ответ обратно. Соответствие «заглушка и оригинал» живёт только в памяти одного запроса. Включается заменой адреса на `https://api.kosareva.cloud/guard/v1`, для Anthropic SDK на `https://api.kosareva.cloud/guard`, на обычном `/v1` маскирования нет.

Страница [152-ФЗ](https://kosareva.cloud/legal/152-fz/) описывает устройство сервиса, а выводы делает ваш юрист.

Проверить Guard можно без запроса к модели: `POST https://api.kosareva.cloud/guard/v1/guard/preview` с вашим ключом и обычным телом запроса покажет, что найдено и как выглядит текст после маскирования.

## 5. Документы

Работаем через российское ИП или через армянское ООО, вы выбираете, что удобнее. Реквизиты обеих сторон на [странице для бизнеса](../business/README.md#реквизиты-и-связь). До оплаты напишите на ceo@kosareva.cloud, какой вариант вам подходит.

Условия [типового договора](https://kosareva.cloud/legal/dogovor-oferta/) с «Kosareva Cloud» ООО (LLC), Республика Армения, налоговый номер 03038101, в редакции от 03.10.2026: право Республики Армения, споры в МКАС при ТПП РФ, оплата авансом. Финальная редакция даётся при заключении.

По оферте счёт, акт и инвойс предоставляются на русском и английском, PDF на почту, бумажные оригиналы по запросу. Акт по оферте оформляется по итогам расчётного периода и считается принятым, если за 5 рабочих дней нет возражений. Если вы выбрали ИП, набор документов согласуем до оплаты. Налоговые последствия закупки оценивает бухгалтерия заказчика. NDA подписываем.

## 6. Ошибки на понятном языке

Шлюз переводит ответы об ошибках на русский и добавляет подсказку, что сделать. Разбор кодов лежит в [справочнике](https://kosareva.cloud/spravochnik/kody-otvetov/).

Проверить можно бесплатно: запрос без ключа вернёт `401` с текстом «Ключ не распознан. Проверьте заголовок Authorization: Bearer sk-... и что ключ не удалён в кабинете.».

```sh
curl -s https://api.kosareva.cloud/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-v4-flash","messages":[{"role":"user","content":"hi"}]}'
```

## Чего у нас нет

- Batch API.
- Выбора канала клиентом и открытого списка каналов.
- Английской документации: `/docs/` на сайте только на русском.

## Вопросы и ответы

### Какие возможности вендоров Kosareva Cloud не поддерживает?

Kosareva Cloud не поддерживает Batch API.

### Где Kosareva Cloud хранит данные?

Кабинет, база пользователей, биллинг и журналы расхода Kosareva Cloud лежат в дата-центре в Москве. Тексты запросов и ответов в журналы шлюза не записываются, исключения для картинок, видео, музыки и озвучки перечислены в [разделе «Данные»](#4-данные). Запрос к зарубежной модели уходит за пределы России.

### Как посмотреть цены Kosareva Cloud без регистрации?

Цены Kosareva Cloud в рублях открыты на [kosareva.cloud/prices/](https://kosareva.cloud/prices/) и в JSON по адресу `https://kosareva.cloud/panel/api/price-catalog`. Ключ и регистрация для этого не нужны.

Нашли расхождение между этим текстом и тем, как ведёт себя API, напишите на ceo@kosareva.cloud или в Telegram [@kosareva_cloud](https://t.me/kosareva_cloud). Исправим документ или сервис и обновим дату редакции.
